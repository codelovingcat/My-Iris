# My Iris

A visual experiment centered around a pair of expressive green eyes.

The project explores how a simple illustration can feel alive through color, light, motion, and subtle interaction. The visual direction is inspired by distinctive **khaki / olive green eyes**, with warm brown tones around the brows and a dark, natural pupil.

## Planned experience

- Two proportionally balanced human-like eyes
- Distinct khaki-green / olive-green irises
- Dark brown, warm-toned eyebrows
- Layered iris detail, shading, highlights, and depth
- Pointer-reactive iris movement
- Natural synchronized blinking
- Atmospheric lighting and subtle motion
- Optional sound / music layer

The project will be built incrementally, starting with the static eye illustration and adding animation and interaction only after the core visual is right.

## Technology

The experience is intended to stay lightweight and browser-native:

- HTML
- CSS
- Vanilla JavaScript
- SVG / CSS-based illustration
- Web Audio API for optional sound

## Status

Early visual development.

The first milestone is focused on getting the eye proportions, iris colors, eyebrows, highlights, and overall composition right before adding blinking or other motion.
